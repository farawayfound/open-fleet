# Code of conduct

This is a small project. The rules are short.

- Be direct about the code and courteous to the person. Review the change,
  not the author.
- Assume competence and good faith; ask before concluding.
- No harassment, no discrimination, no personal attacks, anywhere the
  project's name is on the door: issues, pull requests, discussions.
- Respect people's time. A reproducible report beats a long one; a
  minimal PR beats an ambitious one.

Maintainers may edit, lock or remove content that breaks these rules and may
ask people who repeatedly break them to leave. If something happens that you
would rather not raise in public, use GitHub's private vulnerability
reporting on this repository with "conduct" in the title and it will reach a
maintainer privately.
